# Google Play-afbeeldingen van Tunr

Gemaakt door de workflow *Play Store media* in int-radio-app (`tools/make_playstore_media.py`, opnames uit de echte
Android-app in de emulator). Engels. Bron voor Google Play Console én voor de map `Android/` in de presskit.

| Map / bestand | Inhoud | Maat |
|---|---|---|
| `tunr/en/icon-512.png` | app-icoon (verplicht) | 512 × 512 |
| `tunr/en/feature-graphic-1024x500.png` | feature graphic (verplicht) | 1024 × 500 |
| `tunr/en/phone/` | telefoon (verplicht: min. 2) | 1080 × 1920 |
| `tunr/en/tablet-10/` | 10-inch tablet | 2560 × 1440 |
| `tunr/en/tv/` | Android TV (verplicht voor tv: min. 1) | 1920 × 1080 |
| `tunr/en/tv-banner-1280x720.png` | Android TV-banner (verplicht voor tv) | 1280 × 720 |

Android Auto: Google Play vraagt voor media-apps geen eigen schermafbeeldingen.
